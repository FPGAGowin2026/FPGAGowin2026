# ACG720-138K 迁移版教程模块自检

这是 `portable_25k_bist` 的最终比赛板包装工程，测试逻辑与教程 HDL 保持一致，只改变：

- 器件：`GW5AT-LV138PG484AC1/I0`
- 时钟：`Y18`，50 MHz
- 低有效复位：`F15`
- UART TX：`M15`，115200 8N1
- UART RX：`J21`，用于保持校验和测试向量为运行时输入（空闲高电平）

这些引脚来自原教程多数工程的 CST。当前未连接 ACG720-138K 实板，因此本目录只完成综合、P&R、STA 和 bitstream 生成，不声称 138K UART 实测。
