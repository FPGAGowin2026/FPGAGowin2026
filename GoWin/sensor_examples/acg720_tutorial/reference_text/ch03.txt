3.1 Modelsim 编译 Gowin 器件库
      Gowin 的 IP CORE 或 原 语 仅 在 对 应 的 开 发 平 台 里 使 用 ， 第 三 方 工 具
Modelsim 无法获取 Gowin 的 IP CORE 内部的运行逻辑结果，因此无法直接进行
仿真，需要进行 Gowin 库的编译。本章首先带领大家学习如何编译 Gowin 库，
该步骤需要在第一次使用 Gowin FPGA 的时候进行，而编译出来的库后续可以
随时使用，不用每次仿真之前再编译。

用户可以去我们的论坛上进行下载安装，下载链接如下：
