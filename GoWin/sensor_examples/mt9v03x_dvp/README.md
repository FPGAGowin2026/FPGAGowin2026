# MT9V03X DVP 例程边界

本工程采集 8 位灰度 DVP 流：观察到新的高电平 VSYNC 后，在 HREF 高电平期间每个 PCLK 上升沿发布一个像素。配置口按本地逐飞驱动使用的固定格式发送四字节 UART 帧：`0xA5, command, value[15:8], value[7:0]`，默认 9600 8N1。

工程**不包含**完整上电参数序列、相机应答 UART 接收/超时重试、帧缓存或图像算法。调用方必须依据相机固件版本提交命令并验证模块应答；`cfg_done` 只表示四个字节已经发完，不代表相机接受了命令。像素输出属于 `camera_pclk` 时钟域，跨域使用前需要异步 FIFO。

生产顶层为适配 MG121 封装，以 `debug_select` 选择灰度像素、X 或 Y 到 `debug_data[15:0]`，并将帧事件压缩到 `capture_status[3:0]`。测试台直接连接完整采集与 UART 配置 core，不因顶层窄化而裁掉验证点。
