# Jetson与UDP接入

当前唯一在线网桥是`ugv_ws/src/ugv_bridge`，启动入口为`car_bringup/car_bringup.launch.py`。不再使用已退役的fpga_gateway/mission.launch.py入口，不启动第二个争用控制、视频或遥测端口的网关。

FPGA `192.168.0.2:5000`；Jetson有线默认`192.168.0.4/24`，回执6103、视频6102、遥测6104。PC服务经Jetson现有UDP6200链路访问。未配置有线地址时可绑定0.0.0.0离线启动，但不表示通信通过。

视频为800×480 YUYV422、RTP PT97、BT.709 limited，复用现有组帧/颜色转换/JPEG分支。视频源时间与雷达、融合源时间分别标记，不把主机组帧时间冒充曝光时间。

局部任务使用既有32字节BX72报文，type7八片组成72字节任务，type8 ACK只证明分片接收；导航80字节type8遥测在相反方向按端口解析，带boot_id、odom域、地图版本、64位微秒和执行状态。任务组装必须同会话、连续序号、顺序片号及完整CRC，缺片不能执行。精确字段见[公共合同](refactor_20261024/接口与文件归属.md)。

Jetson发布完整LaserScan、纯轮式里程计、已融合雷达的位姿及odom到base_link TF，保留源时标映射。不要把融合位姿再当独立轮式量重复融合。本轮只接局部odom目标，不接全局SLAM、全局地图或全局路线，也不运行另一个拥有最终运动控制权的ROS局部控制器。

网页/任务服务应区分命令接收、FPGA任务状态及实际机械动作。人工接管会中断局部任务；监看心跳不能产生type3零速覆盖任务。TensorRT/ByteTrack保留，无可靠测距时只做视觉转向。
