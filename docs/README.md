**当前进度（2026-09-23）：实际板卡为 ACG720-60K。** 闭环工程使用 CH0～CH3 恒等映射占位，GPIO0 引脚、轮位和极性仍待实际接线后确认。80 mm 轮径为规格参考，轴距、轮距、每圈计数、测速比例及 PI 参数仍是原型或未知值。当前软件仿真覆盖通道映射、命令收发、到时停止、复位及闭环反馈；Gowin 构建记录见 [Windows 构建说明](../FPGA_ws/docs/windows_motor_build.md)。未烧录、未连接串口发送运动命令、未操作硬件。

下一步按实际线束确认 GPIO0 映射和 I/O 电平，再更新轮位通道映射及极性；之后测量编码器每圈计数、有效轮径和底盘几何，并整定 PI。仿真、构建快照和码流位于 Git 忽略的 build 目录，跨端复查时需一并复制。工作树尚未提交或推送。

用户已确认 IMU660RC 模块的芯片为 LSM6DSV16XTR，采用 SPI；OV5640 按 `E:\project\FPGA_workspace\ch45_ov5640_ddr3_tft` 的 800×480 RGB565、DDR3 帧缓存和板载 TFT 配置开发。参考工程的历史 IP/码流不算当前主线证据，实际所需 IP 须针对 60K 用最新兼容工具重新生成。阶段依赖与验收见[后续开发计划](后续开发计划.md)。

历史赛题、专项报告、生态地图等独立资料不属于当前开发入口；历史记录中的旧路径不代表当前可复跑入口。
