# BX72 EF20 历史状态与当时计划

更新：2026-10-05。范围是本轮传感器遥测与后续依赖顺序；现有两人分工及总体目标见[总计划](后续开发计划.md)。本记录不改变其他进行中任务的归属。

## 当时结论

BXT1 传感器遥测代码、离线验证、候选封存和 SRAM 加载已完成。2026-10-05 本次状态复核通过候选哈希门禁，并当时只读确认板上 User Code 为 0x0000EF20。传感器实测正确性、EF20 并发和真实断链恢复尚未签收。

| 项目 | 状态 | 证据边界 |
|---|---|---|

| 历史断链恢复 | C934 人工刷新 Jetson 静态邻居后恢复已通过 | 无需主机干预的自动恢复尚未证明 |

| 综合布局布线 | RX 路由告警未回归；内部全时钟负端点为 0；Logic 43834、Register 30808、BSRAM 125、DSP 74、latch 1 | 最差 setup 0.000 ns，裕量很紧；外部接口时序核验待完成 |

ROS Header 为接收时刻，FPGA timestamp_us 为采集提交/快照时刻，尚未做跨机时钟映射。N10 组不是完整扫描；编码器计数不是已标定轮速；当前没有输出已标定里程计、LaserScan 或虚构协方差。

## 当时计划返回的输入

第一批为 sensor_only、sensor_coexist、sensor_recovery_auto 的 JSON 和同名 JSONL，注明 EF20、是否刷新邻居、是否重启/断电、断链/接回时机。自动测试失败保持失败记录；若另测人工刷新，使用 manual-neighbor 并单独保存。

第二批为物理参考与操作时间记录，以及 Jetson ROS 构建/测试和话题输出。若缺少某源，先依据健康、WHO、UART 错误、ready 与源丢弃定位采集或传输问题，再安排定向复验。

当时首要里程碑是“EF20 真实传感器数据能解释实物动作，并在视频/诊断共存及断链恢复下稳定运行”。在这个里程碑前，不把遥测传输通过扩大为测速、定位或运动闭环通过。
