# 项目状态与交接

更新：2026-10-18。FPGA 工程各分支已合并并清理，当前源码基线为 `fpga_ws/main@bbc5c95`。本文维护现状和待办，构建配置及协议见 [BX72 README](../FPGA_ws/boards/BX72_138K_robot/README.md)。

## 项目状态与交接

| 范围 | 当前状态 |
| --- | --- |
| BX72 功能 | 两个单通信工程共用电机、IMU、N10、CSM 定位、七状态 EKF、打滑融合及独立避障；CPU/APB 和板载调试串口已移除 |
| 蓝牙版 | UART 9600/8N1，网页控制与 v4 遥测；没有相机、DDR3、以太网 |
| UDP 版 | 三轴手动速度、自动模式、五类遥测与 OV5640/DDR3 视频；没有蓝牙 |
| 内部实现 | 两版完整 PNR/内部时序通过；蓝牙 setup/hold 为 +0.065/+0.169 ns，UDP 为 +0.106/+0.124 ns |
| 合并回归 | 37 个不同 RTL 测试台通过；2760 组打滑数据与独立定点参考的状态/协方差误差为 0 LSB |
| Jetson/ROS | 当前源码在 `ugv_ws/src/fpga_gateway`，启动文件在 `ugv_ws/src/car/car_bringup`；接入与实板联验仍需单独确认 |
| ACG720 / 25K | ACG720 保留独立 TFT/GoRV32/BXT1，资源/时序未通过；25K 仅舵机仿真，引脚和器件待核对 |

两版自动模式默认关闭，切换先停车，控制层租约 200 ms；UDP 新会话先零速解锁。内部时序、仿真或入队 ACK 不代表机械动作、制动距离或定位精度通过。

## 证据与交付缺口

- 2026-10-17 的构建耗时、位流/交付包哈希见 [结构化结果](../FPGA_ws/boards/BX72_138K_robot/docs/single_comm_build_results_20261017.json)。完整结果与原始报告位于产生构建的工作树，`build/` 不随 Git 同步。本机已验证的产物在同级 `fpga_resource_optimization/boards/BX72_138K_robot/build/`，主 `FPGA_ws` 检出没有这些产物。
- 合并时复核了两版输入/产物、工具和交付包哈希及内部时序。缓存/看门狗与主机离线测试通过，2 项 C++ OpenCV/NumPy 集成因依赖跳过。部分脚本仍查找旧 `ros_ws`，尚未适配当前 `ugv_ws`，ROS 独立交叉解码未计为通过。
- 当前单通信版本未烧录、未执行真实运动或外部 IO 签核；旧镜像板测不能作为当前版本验收。主工程原有 13 项 ACG720 归档文件未提交删除继续保留。

## 后续开发计划

1. 按所用版本核对源码、构建选项、位流哈希、顶层和 CST；补齐对应版本的下载候选清单。`build_result.json` 不能直接作为 `program_sram.ps1` 输入。
2. 固定车体完成当前版本的通信、模式切换、租约过期、链路断开及恢复验收；UDP 版同时检查视频和遥测并发。
3. 独立核验编码器整圈计数、轮径、轮距/轴距、IMU 轴向和 N10 外参，再低速验证负载响应、停车和定位误差。
4. 适配 ugv_ws 验证路径，完成 C++/ROS 跨进程接入，再推进 `/cmd_vel`、路径点与整机导航。三人职责统一见 [集群方案](室内异构集群方案.md#8-三人开发分工)。

接线与轮位见 [硬件接口](../FPGA_ws/boards/BX72_138K_robot/docs/hardware_interfaces.md)，Jetson 部署见 [通信接入](Jetson通信与接入.md)。
