# 项目状态与交接

更新：2026-10-18。本地 FPGA 实现提交为 `dec08a5`，已融合 `codex/bx72-ddr-mapping@911a158` 并将建图扩展到 UDP，网页在途改动保持原样。实施与本轮验证见 [DDR 建图融合记录](DDR建图融合记录.md)，构建配置及协议见 [BX72 README](../FPGA_ws/boards/BX72_138K_robot/README.md)。远端 `main` 本轮未推送。

## 项目状态与交接

| 范围 | 当前状态 |
| --- | --- |
| BX72 功能 | 两个单通信工程共用电机、IMU、N10、CSM 定位、七状态 EKF、打滑融合及独立避障；CPU/APB 和板载调试串口已移除 |
| 蓝牙版 | UART 9600/8N1，网页控制与 v4 遥测；DDR3 用于雷达 SLAM 栅格地图，没有相机和以太网 |
| UDP 版 | 三轴手动速度、自动模式、五类遥测与 OV5640 视频；本轮新增雷达 SLAM，与视频共用一套 DDR3 控制器，没有蓝牙 |
| 内部实现 | 本轮最终两版综合通过、无 WARN/ERROR，输入快照与当前源码哈希匹配；没有重跑 PNR。蓝牙 v6 历史 setup/hold +0.004/+0.133 ns 不作为本轮时序结论 |
| 回归证据 | 本轮 mapping 5 项、single_comm 4 项、完整双帧及旧视频入口各 1 项通过；网页 24/24、服务 17/17、构建单测 11/11 通过。原 37 项/2760 组参考属于历史记录 |
| Jetson/ROS | 当前源码在 `ugv_ws/src/fpga_gateway`，启动文件在 `ugv_ws/src/car/car_bringup`；接入与实板联验仍需单独确认 |
| ACG720 / 25K | ACG720 保留独立 TFT/GoRV32/BXT1，资源/时序未通过；25K 仅舵机仿真，引脚和器件待核对 |

两版自动模式默认关闭，切换先停车，控制层租约 200 ms；UDP 新会话先零速解锁。内部时序、仿真或入队 ACK 不代表机械动作、制动距离或定位精度通过。

本轮按追加要求将 DDR 地图扩展到 UDP，视频与地图地址隔离，访问通过仲裁共享一套 DDR3 IP。两版均没有地图上行和网页/ROS 地图发布。网页的雷达点、扇区与轨迹不是 DDR 栅格地图；独立 N10 避障不读取该图。蓝牙 `led[1]` 已改为 DDR 校准及初始清图完成，UDP 指示灯仍沿用相机/DDR 校准含义。

## 证据与交付缺口

- 2026-10-17 的原单通信构建与位流/交付包哈希见 [结构化结果](../FPGA_ws/boards/BX72_138K_robot/docs/single_comm_build_results_20261017.json)；加入 SLAM 后的蓝牙分支构建见 [2026-10-18 记录](../FPGA_ws/boards/BX72_138K_robot/docs/radar_slam_build_results_20261018.json)。原始报告和位流位于各自产生构建的工作树，`build/` 不随 Git 同步，不能从记录推定本地已有匹配产物。
- 合并时复核了两版输入/产物、工具和交付包哈希及内部时序。缓存/看门狗与主机离线测试通过，2 项 C++ OpenCV/NumPy 集成因依赖跳过。部分脚本仍查找旧 `ros_ws`，尚未适配当前 `ugv_ws`，ROS 独立交叉解码未计为通过。
- 当前融合版本未烧录、未执行真实运动或外部 IO 签核；旧镜像板测不能作为当前版本验收。Micron 官方颗粒模型仿真仍待模型及兼容仿真器；mapping 快速 UI 模型不能代替 DDR PHY/颗粒时序。

## 后续开发计划

1. 对融合后的两版核对源码、构建选项、位流哈希、顶层和 CST，重新生成匹配构建证据；蓝牙 SLAM 分支 sensor setup 仅 +0.004 ns，需优先复核。补齐对应版本的下载候选清单，`build_result.json` 不能直接作为 `program_sram.ps1` 输入。
2. 固定车体完成当前版本的通信、模式切换、租约过期、链路断开及恢复验收；UDP 版同时检查视频和遥测并发。
3. 独立核验编码器整圈计数、轮径、轮距/轴距、IMU 轴向和 N10 外参，再低速验证负载响应、停车、定位误差、两版 DDR 建图/回环重建及 UDP 视频并发。
4. 适配 ugv_ws 验证路径，完成 C++/ROS 跨进程接入，再推进 `/cmd_vel`、路径点与整机导航。三人职责统一见 [集群方案](室内异构集群方案.md#8-三人开发分工)。
