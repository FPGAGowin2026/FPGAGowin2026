## 下一步顺序

1. 核对这份候选与接收器，加载后记录位流哈希和板上身份。
2. 四轮悬空验收视频、五类遥测、WASD 同时运行，检查松键、失焦、网关退出、命令断流、实际断网及重连后重新使能。

5. 复用已验证的 UDP 协议接入 ROS `/cmd_vel`，再推进编码器＋IMU 定位、N10 校正、近障停车和导航。
