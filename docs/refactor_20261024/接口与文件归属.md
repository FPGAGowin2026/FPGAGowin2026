## 数值、时间与运动

- odom右手系：x前、y左、z上，yaw逆时针。位置signed32米Q16，yaw signed32弧度Q16。车体速度字段为signed16 mm/s、mm/s、mrad/s，顺序`{vx,vy,wz}`；世界速度必须旋转后再送轮控。
- 几何乘积至少signed64；累加按范围再加guard bits。右移默认向负无穷取整，通信/除法向零截断。新规划定点核要明确其逐项舍入；所有溢出使候选无效，不能饱和后成功。
- FPGA规划域50MHz，64位单调微秒时间；64位域内正常比较，禁止用32位年龄跨回绕。旧遥测32位us在Jetson各流展开并共同映射，保留源时间。
- odom域32位，在复位/坐标重置时失效全部旧任务；CSM参考generation与odom域分开。map(0,0)为左下角，格坐标signed32整数，64mm/格，负坐标floor。障碍地图与CSM匹配参考分离。
- 车体包络采用可配置外接半径，默认保守320mm，再加跟踪/定位余量64mm、曲线误差8mm与半格对角46mm；这些是未经机械标定的原型参数，不是硬件安全验收。未知、地图外、陈旧传感器/定位均拒绝运动。
- 50Hz跟踪，10Hz规划是目标；无合格轨迹停车受阻。旧轨迹只有同任务/odom域、未过期且在当前快照完整复查合格时才可短时沿用。新轨迹位置/速度连续，最终转向单独进行。

## 扫描、地图与规划接口

A的`rolling_obstacle_map`对顶层接收clk/rst、now_us[63:0]、odom_domain_i[31:0]、pose_valid_i、pose_x/y/yaw_q16_i、pose_stamp_us_i[63:0]以及逐点`sample_valid_i,point_valid_i,angle_cdeg_i[15:0],distance_mm_i[15:0],packet_error_i`。内部连接独立scan_cache，溢出/丢点/坏圈拒绝整圈。不允许把无回波当已知空闲；运动补偿不足时以保守扫描运动/时长界拒收。

A输出`map_valid_o,map_version_o[31:0],map_stamp_us_o[63:0],map_odom_domain_o[31:0],origin_x_cell_o/origin_y_cell_o signed32`及drop/error计数。`snapshot_acquire_i`脉冲在map有效时锁定最新完整bank，`snapshot_locked_o`与`snapshot_version_o[31:0]`表明锁定；`snapshot_release_i`释放。一次最多一个锁定者，读锁存在时不能覆盖其bank；写端无空bank则延迟/拒收。occupied/free/unknown和inflation完整后才发布同一版本。

地图查询：`query_valid_i,query_ready_o,query_x_q16_i,query_y_q16_i`握手；同一时刻最多一笔未完成请求；`query_rsp_valid_o,query_known_o,query_occupied_o,query_inflated_o,query_version_o[31:0]`。有锁时查询锁定bank，否则查询最新bank；地图外返回known=0。root仲裁B与统一运动guard的请求，不增加第二套地图RAM。A必须提供有限响应延迟说明。

B的`bx72_bspline_planner`作为规划/轨迹模块集的唯一顶层：`clk,rst,now_us[63:0],odom_domain_i[31:0],pose_valid_i,pose_x_q16_i,pose_y_q16_i,pose_yaw_q16_i,pose_stamp_us_i[63:0],measured_vx_mm_s_i/measured_vy_mm_s_i/measured_wz_mrad_s_i signed16`；`task_valid_i,task_ready_o,task_id_i[31:0],goal_x_q16_i,goal_y_q16_i,hold_yaw_q16_i,final_yaw_q16_i,max_speed_mm_s_i[15:0],max_accel_mm_s2_i[15:0],tolerance_mm_i[15:0],yaw_tolerance_mrad_i[15:0],expiry_us_i[63:0],cancel_i`。task_valid只在接受新任务时握手，模块内部滚动10Hz重规划及50Hz执行。

B直接消费A的map metadata、snapshot locked/version及query应答，输出`snapshot_acquire_o,snapshot_release_o,map_query_valid_o,map_query_x_q16_o,map_query_y_q16_o`，输入`map_query_ready_i,map_query_rsp_valid_i,map_query_known_i,map_query_occupied_i,map_query_inflated_i,map_query_version_i`。输出`command_valid_o,command_velocity_o[47:0],status_o[7:0],error_o[7:0],active_task_id_o[31:0],used_map_version_o[31:0],candidate_count_o[31:0]`。

状态：0 idle，1 accepted，2 planning，3 executing，4 reached，5 blocked，6 expired，7 stale，8 numeric，9 cancelled，10 odom_reset，11 capacity，12 link_lost。error记录具体拒绝原因。valid/ready仅在双方为1的时钟沿消费，发起方保持数据；应答只在真实处理后出现。

## 任务传输与跨端协议（唯一主线程维护）

复用UDP 5000接收、6103 ACK、6104遥测、6102视频。旧32字节BX72 v1 probe/type3速度与type5模式保留；不加另一个在线网关或端口。新type7=任务分片，type8=分片接收ACK；仍是32字节，header seq/token和CRC16与旧报文一致。data的10字节为index[0..7]+9字节内容，8片组成72字节任务。分片必须同session、序号严格连续、index依次0..7、在200ms内收齐；缺片/重片/交错不得提交。ACK只代表RX接受分片，最终任务接收/拒绝/到点来自导航状态遥测。

72字节任务网络大端布局：0 version=1；1 action（1 start，2 stop，3 cancel）；2 mode（0 manual，1 vision，2 cooperative，3 independent）；3 flags（bit0允许协同断链续行，其余0）；4 task_id u32（每boot按模2^32半量程严格递增，旧/重复ID拒绝）；8 odom_domain u32；12 boot_id u32；16 goal_x i32 Q16；20 goal_y；24 hold_yaw；28 final_yaw；32 max_speed u16；34 max_accel u16；36 tolerance_mm u16；38 yaw_tolerance_mrad u16；40 expiry_us u64；48 reserved u64=0；56 sent_at_us u64；64 horizon_ms u16（本版只允许0，使用内部有界默认）；66..71 reserved=0。start只允许模式2/3；速度1..300、加速1..1000、tolerance1..500mm、yawtol1..1000mrad；有效期必须在未来且最多120s，sent_at不能来自未来且年龄≤500ms。人工/视觉走现有速度入口，200ms过期停车。协同断链未许可则停车；许可则至task expiry；独立任务不依赖网络心跳，但仍依赖传感器/定位/任务期限。停止/取消、显式人工接管使旧任务无效。

boot_id由本次硬件复位后的第一个合法零速握手token低32位建立，未握手不可收任务；这是会话启动标识，非掉电持久随机ID，主机重连必须读取当前状态。odom_domain初值1；未来显式odom reset必须递增，不允许CSM参考更新触发它。

C后续接入主线程已写、尚未验证的C++API：`struct NavigationTask { uint8_t action,mode,flags; uint32_t task_id,odom_domain,boot_id; int32_t goal_x_q16,goal_y_q16,hold_yaw_q16,final_yaw_q16; uint16_t max_speed_mm_s,max_accel_mm_s2,tolerance_mm,yaw_tolerance_mrad; uint64_t expiry_us,sent_at_us; uint16_t horizon_ms; };` `Bytes encode_navigation_task(const NavigationTask&)`返回72字节；`NavigationTask decode_navigation_task(const Bytes&)`拒绝非法长度/字段；`std::vector<Bytes> fpga_task_packets(uint32_t first_seq,uint64_t token,const NavigationTask&)`返回8个32字节type7；`valid_ack`支持type7/8。C在同一ACK串行队列逐片发送，禁止把8片ACK当执行完成。

导航遥测type8复用现有BX72头（magic/version/type/len/seq/stamp32），payload64字节：boot_id32、odom_domain32、task_id32、map_version32、now_us64、expiry_us64、status8、error8、mode8、flags8、vx/vy/wz signed16、reserved16、goal_x/goal_y signed32、candidate_count32、map_age_us32、pose_age_us32；整个包80字节。`decode_telemetry`返回stream=`navigation`，字段与上述snake_case一致。该流有64位源时标，C优先用它校准旧32位流。任务拒绝应有明确状态，而非固定成功。
