# 四轮麦轮机器人后续开发计划

更新：2026-10-05。最新 BX72 296674D6 候选已完成离线验证与完整构建，尚未加载实板。已实现 UDP 三轴速度、独立 WASD 网关、看门狗和 RX 相位训练；这些功能进入验证阶段。配置/身份见[项目状态](project_status_20261005.md)，命令见[遥控手册](../FPGA_ws/boards/BX72_138K_robot/docs/pc_wasd_teleop.md)。

## 三人分工与交付

人员 A 负责 FPGA/通信，人员 B 负责底盘与物理标定，人员 C 负责 Jetson/ROS 与数据记录。阶段顺序不变，硬件操作由 B 统一安排，A 配合板级加载/逻辑核对，C 同步记录。已有轮位/极性结果复用，不重复从零辨认。

| 人员 | 现在执行的任务 | 交付物 | 后续职责 |
| --- | --- | --- | --- |
| A：FPGA/通信 | 核对 296674D6 清单；配合加载并记录板上身份；悬空测试 UDP 回执、300 ms 超时停车、链路掉线与 RX 相位重训练；问题按波形/日志定向修复 | 位流/源码/脚本版本表、并发与恢复记录；若改 RTL，重新回归/构建/封存 | 保持控制仲裁/停车，接入近障约束与软核任务接口 |
| B：底盘/标定 | 复核当前线束与轮向；手转输出轮一圈测计数；测轮径/几何；悬空低速方向/速度响应，再落地前后/横移/旋转/停止验证 | 每轮计数/圈与参数表、目标/实测速度、动作视频及停止表现；标记哪些已测、哪些参考 | 负载闭环、机械安装外参、实车定位与路径点验收 |

当前可并行：A 核对候选和通信配置；B 在无运动输出条件下测整圈计数/尺寸；C 准备网关、记录工具和 ROS 适配。首次悬空验收三人共同完成；低速落地依赖悬空停车与测速尺度核对，ROS 实车控车依赖现有网关基线验收。近障停车、定位与导航按后续阶段推进。

## 第一轮共同交付

1. A 提供加载身份/哈希与通信结果，B 提供动作/计数/停止记录，C 提供同时间段的日志与目标/实测曲线。
2. 汇总每项通过/失败、环境、配置和故障触发时刻；一次只调整有证据支持的参数或逻辑。
3. 三人确认当前候选的悬空并发、断命令停车和断网恢复结果，再安排低速落地；不要仅凭回执或视频判断动作正确。

## 下一共同里程碑：当前候选的遥控并发与停车

1. 位流 SHA256、板上身份、源码提交及接收脚本对应 296674D6 清单；不得沿用旧 C934/EF20/CC71756F 身份。
2. 四轮悬空下检查前后、横移、斜向、正反旋转及零速度；同时记录请求速度、目标/实测轮速、编码器、IMU、回执与视频。
3. 验证松键、窗口失焦、客户端关闭、网关退出、命令断流及实际断网后的停止；记录触发到 PWM 停止/物理停转的时间。
4. 重连后确认相位训练、零速握手及重新使能；区分自动恢复与人工刷新邻居等操作。
5. 保存测试条件、视频/原始日志、错误/序号缺口/源丢弃统计和失败记录；入队回执不计作机械闭环达到目标。

门限和通过标准按已有脚本及实测条件记录。内部 STA 通过不代表停止距离、测速比例或外部 IO 时序通过。

## 已实现接口与待标定项

协议为 BX72 v1，大端 32 字节速度包 type=3/4，FPGA 5000、Jetson 6103；本机约 50 Hz 更新请求、Jetson 约 20 Hz 转发、FPGA 非零速度看门狗约 300 ms。详细新鲜度/会话和恢复行为见[数据契约](udp_protocol.md)。这不是旧差速格式。

轮序 A/B/C/D=FL/FR/RL/RR，映射 0xD2、电机反向 0xB、编码器反向 0xA。当前 122880 count/输出轮圈、98 mm 轮径、160/196 mm 轴距/轮距仍需物理核验。ROS Header 为接收时间，FPGA timestamp_us 为采集提交时间；定位前需确定时钟映射、外参、噪声和唯一 TF 发布者。

## 后续顺序

候选实板并发/停车 → 整圈计数及传感器核对 → 低速落地负载 → ROS `/cmd_vel` → 编码器/IMU 定位 → N10 校正 → 路径点/绕障 → 整机长时验收。近障减速/停车可在低速控车后独立推进。

基础任务独立部署按[赛题规划](赛题FPGA部分实施规划.md)执行。ACG720 先处理自身 DDR 负时序路径，不能使用 BX72 的放行结论。
