# 控制与连续局部定位

车体系x前、y左、z上，yaw逆时针；odom连续，参考子图重建不得使执行位姿跳变。位置/航向使用signed32米/弧度Q16，车体命令使用signed16 mm/s、mm/s、mrad/s。轮位、编码器映射、原电机闭环和PWM保留。

定位匹配参考与导航障碍图是两份独立数据：前者服务CSM/EKF，后者服务射线清障、未知区、膨胀、窗口滚动和一致快照。参考generation不能代替odom域编号。地图版本与原点随完整快照原子发布。

BX72最终只有一个电机入口。人工/视觉请求有200ms租约；协同任务按明确的断链续行标志与任务期限处理；独立任务不依赖网络心跳，仍受任务期限、定位和传感器新鲜度约束。人工接管、取消、过期和无可行轨迹都停车。未选中来源不能靠零速心跳覆盖任务。

样条初值、坐标微调与最终硬检查共用评价核；源码复用不等于多个实例共用一块乘法器。硬件时分调度、查询容量与超时以板级local_spline/local_map文档为准。车体扫掠包含未知与窗口外，各轮速度/加速、数值溢出和任务有效期不能用成本下降代替。

本轮不实现全局地图。机械外廓、传感器外参、轮径、噪声、停车加速度和响应延迟仍需实测，当前参数仅为研究原型输入。历史失败证据保留在重构前备份与Git历史；旧通过结果不适用于新输入。
