# 电机软件验证记录（2026-09-23）

本记录对应当前 ACG720-60K 电机闭环工程。所有结果均来自软件测试或离线工具；未连接串口发送运动指令，未烧录，未操作硬件。

## 清理与配置

已移除旧电机辨识/闭环工程的可读源码、约束、文档、测试、日志和文本构建快照。闭环行为保留在通用核心 `FPGA_ws/rtl/system/at8236/mecanum_motor_closed_loop_core.sv`，通道映射分别由板级配置传入；当前 ACG720 配置采用恒等映射和零极性占位。每圈计数未知，测速比例与几何/PI 参数仍是原型值。与电机目标无关的其他历史示例保持不变。忽略目录中仍有少量旧 Gowin 二进制缓存（`.db`、`.binx`、`.bin`、`.p`），不再有对应源码快照、日志或码流文件；当前工程不引用这些缓存。

日志分析器只保留通用四路帧解析和闭环/原始通道列布局；测试帧为合成数据，不再依赖旧接线日志。分析器不翻转极性，没时间依据不输出计数率，不输出未标定的 mm/s。

## 软件验证

- Python 3.12：`sim/tools/test_motor_log_analyzer.py` 共 24 项通过，覆盖帧解析、32 位有符号数、回绕、无效行、时间前缀与间隔、布局和 CSV/SVG/JSON 输出。
- Icarus Verilog：`tb_motor_closed_loop checks=35 frames=22`、`tb_acg720_60k_motor_wrapper checks=7`、`tb_mecanum_serial_divider samples=58` 均通过，PowerShell 运行脚本退出码为 0。`-Wall` 保留了通用 RTL 对数组 `@*` 敏感列表的提示，不影响仿真结果。完整日志见 [仿真记录](../FPGA_ws/build/sim_acg720_60k_motor_closed_loop/20260923-223207-152/simulation.log)。
- Gowin V1.9.12.03（64 位）：工程目标 `GW5AT-LV60PG484AC1/I0` / `GW5AT-60B`，综合、布局布线及 STA 通过；退出码 0，50 MHz 约束下 Fmax=55.824 MHz，分析 15,317 条路径，setup/hold 违例均为 0。资源 Logic 6,534/59,904、Register 3,863/60,780、CLS 4,644/29,952、I/O Port 20/297、DSP 22/118。新码流 SHA256 为 `FE83F74F4F687C3908326F0F67F9DC90FAA481E0F593D42D7E274BEE198435CE`；源码快照清单 SHA256 为 `EA34F593739DDA8075F3040662D68862F11D6136E23A32C176E18802888824AC`。完整记录见 [构建清单](../FPGA_ws/build/acg720_60k_motor_build/20260923T141736765Z_39468_acg720_60k_motor_closed_loop/manifest.json)、[日志](../FPGA_ws/build/acg720_60k_motor_build/20260923T141736765Z_39468_acg720_60k_motor_closed_loop/build.log)和 [Windows 构建说明](../FPGA_ws/docs/windows_motor_build.md)。
