# 赛题 FPGA 部分实施规划

更新：2026-10-05。本文件对照此前提供的赛题截图规划基础任务，正式演示和平台限制按赛事文件执行；工程现状见[主项目 README](../README.md)，三人排期见[开发计划](后续开发计划.md)。

## 任务与部署边界

基础任务按 FPGA＋软核独立完成的方向实施。当前主线为 BX72 / GW5AT-138C，ACG720-60K 保留独立集成工程；资源与时序按实际部署板卡验收。Jetson 用于调试、显示、记录和允许的扩展，不能以 Jetson 联调代替基础任务独立导航证据。

| 任务 | 实现内容 | 验收证据 |
| --- | --- | --- |
| 1．多传感器感知 | OV5640 采集/显示、IMU 姿态采集与显示 | 实时画面和姿态演示、频率/连续性与物理测量记录 |
| 2．运动控制 | 前后、转向、定点旋转；四轮编码器速度闭环 | 目标/实测轮速、方向、速度响应和实际动作 |
| 3．实时避障 | 测距、障碍检测、自动减速/停车及局部绕障 | 障碍条件、响应时间、停止表现和绕障重复实验 |
| 4．自主导航 | 起终点移动、路径点到点、障碍绕过及返回路线 | 外部真值/轨迹、到点误差、重复成功与失败记录 |
| 5．视觉识别扩展 | 检测指定目标；画面显示或视觉特征不等于识别完成 | 场地目标识别与误检记录 |
| 6．智能任务扩展 | 搜索、接近与任务执行 | 识别→导航→执行的完整演示 |

此前评分摘录为 FPGA 实时感知控制 40%、稳定性 25%、自主导航 20%、创新 10%、AI 扩展 5%；据此先推进基础链路和稳定性，再做扩展。

## 当前起点

UDP 双向诊断及视频共存已完成实板验收，用户确认电机辨认完成。IMU/N10/编码器 BX72 v1 遥测已有远端 round5 短窗口实板记录，本地 296674D6 融合候选已完成离线回归、完整构建及内部 STA，未烧录；最新结果由[基线记录](../FPGA_ws/boards/BX72_138K_robot/docs/baseline_unification_20261005.md)维护。

已有四轮运动学、速度环和七状态定点 EKF，不再把这些列为从零开发任务。当前需验证标定与真实响应，并复验已融合的 UDP 运动控制与停车。实现细节分别维护在[运动控制](motor_development.md)、[EKF](robot_fpga_ekf.md)与[数据契约](udp_protocol.md)，本文件不重复算法或寄存器。

BX72 的 OV5640→DDR3→UDP 视频有实板证据，TFT 已移除；ACG720 保留 TFT。基础任务 1 的最终显示位置与独立运行要求需对应演示口径确认，不能只凭主机收包签收姿态显示。

## 实施顺序

| 阶段 | 主要工作 | 收口条件 |
| --- | --- | --- |
| A．候选实板与标定收口 | 先复验 296674D6 的悬空并发/停车，再核对每圈计数/轮径/几何、速度响应与传感器 | 配置与实物一致，真实轮速/IMU/N10 数据可追溯 |
| B．UDP 运动闭环 | 复验已有 vx/vy/wz、停车及轮速反馈，低速落地后接入 ROS /cmd_vel | 基本动作、断命令停车及并发记录 |
| C．定位与反射 | 实测编码器＋IMU EKF，再验证 N10 校正；近障直通减速/停车 | 轨迹误差、观测失效和停车表现可复现 |
| D．软核导航 | 路径点序列、到点判断、局部绕障、重回路线 | 起终点/路径点/绕障的独立运行演示 |
| E．整机验收 | 相机、采集、定位、导航与四轮控制合并 | 实际板卡资源/STA、位流哈希、长时运行和任务 1～4 逐项演示 |

A 中已有标定结果直接复用；B 复用已实现的 WASD/Jetson 网关与速度协议，优先验证而非重复实现；近障停车不依赖完整 EKF 验收。不同阶段分别记录仿真、综合/时序、板测与实车证据。

## 定位与 SLAM 边界

先验证当前编码器＋IMU 局部定位，N10 扫描匹配质量、外参和时间处理通过后再校正。原始雷达点不是位姿观测；已有局部子图原型不具备完整回环或全局地图能力。

| 场地条件 | 后续方案 |
| --- | --- |
| 已知或允许预先测绘 | 验证雷达对固定地图/标志的定位，按路径点导航 |
| 短路线、局部绕行 | 有界局部定位/地图和路径跟踪，量测累计漂移 |
| 未知长路线、重复经过或严格全局精度 | 单独评估在线建图、重定位、回环及资源预算 |

完整 SLAM 若成为基础任务要求，需验证其 FPGA＋软核部署，不能用扩展平台替代。EKF→SLAM→map/odom 修正的接口在[系统方案](系统总体方案.md)和实现文档中维护，避免未经处理的相关观测回授。

## 视觉与待记录参数

摄像头先完成画面和姿态显示，再按场地需要增加轻量路标/引导线特征或目标识别。视觉进入定位前需有可解释的几何观测、标定、采集时间与质量；颜色区域中心不直接表示距离或完整位姿。

后续记录包含：辨认配置与位流版本、测速/几何参数来源、速度响应和停止表现、IMU 轴向与零偏、N10 安装外参与扫描时序，以及场地、障碍、路径点精度和地图要求。具体数值归入对应工程文档，避免多处维护不同默认值。
