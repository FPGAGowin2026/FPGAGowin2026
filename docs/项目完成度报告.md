# 项目完成度报告

更新日期：2026-08-24

## 1. 结论

按“最终能够稳定完成现场演示”计算：

- 总体完成度：约 **38%**。
- 剩余工作量：约 **62%**。
- 合理估算区间：35%～41%。
- 当前阶段：主机通信、高级功能和 FPGA 纯 RTL 仿真底座已建立；机器人网络 RTL 完成完整帧端到端自检、三项 Gowin 综合以及 14-I/O 离线 wrapper 的布局布线与内部 STA。真实系统时钟、PHY/PCB I/O delay、完整板级管脚、电机/传感器和实板闭环仍未完成。

该比例不是按代码量或工期计算，而是按最终演示所需的 FPGA、底盘、传感器、导航、AI 和稳定性门槛加权。当前前期软件基础完成较多，但尚未形成完整实板运动闭环。

已发布分仓基线为：`fpga_rtl` `7922400`、`fpga_gateway` `88f760c`、`robot_bringup` `c188c99`。`7922400` 包含本报告所述的机器人网络 RTL、自动化自检、Gowin 离线综合和布局布线工程。三个高级功能包、依赖脚本和本文档由父仓库直接维护。

## 3. 已完成工作

### 3.1 架构与协议

- 已确定 ACG720 与 Jetson Orin Nano 的职责边界。
- 已冻结 FPGA 独立模式与 Jetson 协同模式的安全优先级。
- 已定义固定二进制 UDP 报文、黄金向量、端口和频率目标。
- 父仓库、`fpga_rtl`、`fpga_gateway` 和 `robot_bringup` 的仓库边界及同步方式已建立。

### 3.2 ROS 主机侧

- `fpga_gateway_node`、`fake_fpga_node` 和 `robot_bringup` 已实现。
- 4/4 协议 GTest 已通过。
- 主机仿真闭环已验证约 100 Hz 遥测、速度命令、200 ms 命令超时归零、软件急停和断链诊断。
- `robot_navigation` 已用 `robot_localization`、`slam_toolbox` 和 Nav2 完成合成传感器点到点导航。
- `vision_bridge` 与 `mission_control` 已完成合成红色目标的搜索、对准、接近和停车闭环。
- 上述三个高级功能包的运行时节点已迁移为 C++17/`rclcpp`，对应纯算法回归已改为 GTest；Python 只保留给 ROS 2 launch。
- 当前五包已在独立 `/tmp` 构建目录复验成功；4 项协议、1 项 UDP launch 和 3 项算法共 8 个直接用例通过。`colcon test-result` 显示的 13 条记录包含 CTest 包装层重复汇总，不能当作 13 个独立用例。
- 同轮运行复现 `120×80 @ 0.05 m/pix` 地图、Nav2 从 `(0, 0)` 到 `(1, 0)` 成功和任务状态到达 `COMPLETE`；网关与 bringup 发布版本还增加了待实车标定的里程计/IMU 协方差初值。

### 3.3 FPGA RTL

- 模式仲裁器已实现独占选源、安全强制置零和停车后切换。
- Verilog-2001 编译和 15 项自检已通过。
- 已从官方第 58 章工程导入 RGMII/GMII、IPv4/UDP 收发和回环模块，并新增自检 testbench。
- 72 字节合法帧逐字节回环、坏 FCS/描述符 FIFO Full 信号注入整帧拒绝，以及拒绝帧后不同负载合法帧均现场通过；负载与元数据现在按同一提交条件原子提交或回滚，真实 FIFO 填满竞争尚未获得器件证据。
- Control 解析 10 项自检覆盖黄金向量、应用层 CRC、以太网错误、错误头、30/32 字节异常长度、重复序号和 `0xffffffff → 0` 回绕；Telemetry 固定 72 字节编码、CRC 和四拍背压保持通过。
- `acg720_robot_network_rgmii` 已连接 RGMII/GMII、IPv4/UDP Control、`robot_rtl_core`、72 字节 Telemetry、38 字节 Status、最小 ARP responder 和 ICMP Echo Reply。两个异步时钟域使用深度 4 的整记录 FIFO，复位分别同步释放，电机 PWM/方向输出保持未连接。
- `tb_robot_network_e2e` 的 72 项检查覆盖 ARP、连续 ICMP、合法与错误 Control、Telemetry/Status 字节、错误 FCS 后合法帧、IPv4/UDP/应用 checksum、目标 MAC/IP/端口、重复/倒序/回绕序号、FIFO 满、测距减速/停车、看门狗、急停、严重故障、复位和不同频率/相位时钟。
- OV5640 DVP RGB565、IMU 六轴原子提交、三路测距偏置/量程/超时、AB 解码、轮速估计、差速 PI、减速停车、左右绕障和路径段执行均有自检。
- `robot_rtl_core` 已完成系统级连接，并验证内部四段演示路径、两种模式、软件/物理急停、严重故障、旧目标失效、零目标清 PWM、看门狗和 Jetson 安全限制；真实路径进度生成器仍只是接口骨架。
- `FPGA_ws/Scripts/run_all_sim.sh` 本轮运行 10 个 RTL 功能 testbench 和 1 个 Gowin PLL/RGMII 板级展开检查，全部通过；模式仲裁、Control、传感器、自主运动、电机、系统组合、异步 FIFO 和网络端到端分别为 15、10、37、18、9、21、23、72 项检查，Telemetry 与回环另做整帧自检。
- 通用 IPv4 checksum、辅助 ICMP/IP checksum 和发送字节选择已分阶段寄存；ARP/ICMP 字节、IPv4/ICMP checksum 与 FCS 保持正确，连续请求无跨帧污染。`gmii_to_rgmii` 未定宽常量/generate warning 和轮速算术截断 warning 已消除；轮速控制明确使用幅值低 16 位、饱和到 PWM 上限，并保留零目标清状态行为。
- Gowin V1.9.12.03 对官方 UDP 回环、机器人逻辑顶层和离线 wrapper 的综合均以退出码 0 完成。逻辑顶层使用 6,577 个寄存器、7,437 个逻辑单元和 29 个 BSRAM，报告 10 条 warning；125 MHz 网络 PLL 域综合估算为 158.532 MHz。562 个 I/O Buffer 属于逻辑可观察性顶层，仍不能直接上板。
- 两个 `range_safety_limiter` 的层次被综合等价扁平化，但综合网表保留 `front_distance_mm_i` 到最终线速度及 `status_bits[4]` 的安全锥，端到端测试验证 400 mm 减半、100 mm 停车和恢复。摄像头/电机链路在无物理输出时允许被移除；官方 `pll_init.v` 两条截断 warning 未修改。
- 14-I/O 离线 wrapper 只复用官方 ch58 RGMII/复位管脚，未知输入使用失效安全常量，系统域使用 RGMII RX `/2` 的 62.5 MHz 工具时钟。最终 P&R/STA 使用 6,556 个逻辑单元、5,832 个寄存器和 58 个物理 BSRAM primitive；35,356 条路径、20,381 个端点中 setup/hold 违规均为 0，网络域 Fmax 129.443 MHz，最差 setup slack `+0.275 ns`。没有猜测 PHY/PCB I/O delay，码流未上板，因此不证明最终板级时序或实车安全。

## 4. 剩余工作

### 4.1 FPGA 网络与协议

- 固化实际系统时钟、复位、PHY 状态和板卡约束，从离线 wrapper 派生最终板级顶层。
- 根据 PHY 时钟关系与 PCB 延迟补齐 RGMII `set_input_delay`/`set_output_delay`，再执行最终板级 P&R/STA。
- 在电机输出禁用状态下完成 RGMII、ARP、Ping 和 UDP Control/Telemetry/Status 实板验证。
- 在电机禁用状态下完成 FPGA—ROS 黄金报文实板联调。

### 4.2 FPGA 安全与运动

- 将已可综合的模式仲裁器和安全限速锥保留在真实板级 wrapper 中，接入实际安全输入并重新完成布局布线检查。
- 实现物理急停断电接口、加速度限幅和堵转检测；现有逻辑看门狗不能代替物理链路。
- 将 AB 输入、PWM 和方向输出接入真实顶层并完成电机参数标定。

### 4.3 感知、避障与独立演示

- 按最终型号完成 OV5640 配置、IMU 和三路测距协议驱动、CDC、DDR3 与 HDMI 状态显示。
- 用编码器/IMU 实测进度替换 testbench 进度，标定减速、停车、绕障和路径参数。
- 完成 FPGA 独立路线连续演示和实车参数标定。

### 4.4 Jetson 高级功能

- 在 Jetson 上运行依赖安装脚本重建本地 `ros_ws/src/external` 覆盖层，或经确认后改用系统级 Humble 依赖；该本地目录不上传。
- 接入真实 IMU、2D 激光雷达和相机，测量 TF 外参并标定融合协方差。
- 用真实数据替换合成激光与相机，保存 rosbag、地图和导航成功率证据。
- 选择单个 TensorRT 目标模型并把输出适配到 `/vision/target_observation`；当前红色阈值算法只作为接口基线。

### 4.5 系统收口

- 验证断网后 200～300 ms 内关闭 PWM。
- 验证图像满负载不阻断控制通道。
- 完成故障注入、1～2 小时连续运行和现场演示材料。

## 5. 当前关键路径

后续按以下顺序推进：

1. 固化引脚、电平、真实系统时钟、复位、PHY 与外设型号清单，从离线 wrapper 派生最终板级顶层。
2. 根据 PHY/PCB 数据补齐 RGMII 输入输出 delay 和板级 CDC/复位约束，重跑最终 P&R/STA。
3. 完成 RGMII、ARP、Ping、UDP 实板回环和电机禁用的 FPGA—ROS 黄金报文联调。
4. 架空车轮完成物理急停、看门狗、编码器、PWM、限幅和堵转门槛。
5. 接入真实摄像头、IMU、测距、DDR3/HDMI，标定绕障和独立路径。
6. 接入 ROS 融合、SLAM、Nav2，再完成 AI、网络传图和稳定性收口。

当前不上实板时，RTL、自动化和离线实现已到达可可靠验证的边界。下一不可替代门槛是 **实际外设清单、PHY/PCB I/O 时序、最终机器人板级集成和实物验证**；在硬件条件具备前不继续扩展算法、模型、网络传图或通用框架。

## 6. 风险与证据边界

最大风险现已从内部网络组合路径和逻辑顶层 I/O 数，转移到未知 PHY/PCB I/O 时序、真实系统时钟、完整板级接口以及尚未完成的电机和传感器集成。官方 RGMII 管脚、器件号和 PLL 已固化到离线基线；实际系统时钟、电机驱动、编码器、IMU、测距和急停引脚仍未固化。Icarus 11 通过 `/tmp/fpga_gowin_iverilog` 运行 10 个 RTL 功能自检和 1 个板级展开检查；该临时工具链不是仓库资产。三项综合和一次离线 P&R/STA 已产生被 Git 忽略的报告与码流，但 ROS、RTL 仿真、综合和离线实现均不能替代实物证据。

当前结果不能证明：

- 最终板级 Gowin 时序或 RGMII I/O 时序正确；当前只证明安全常量离线 wrapper 的内部时钟路径通过。
- 本项目 CRC16、序号、逻辑心跳和 PWM 目标能够在实际 PHY、器件时钟与板级连接下工作；PHY 断链和物理 PWM 关闭仍完全未验证。
- 电机、传感器、SLAM、Nav2 或 AI 可以在实物系统运行。
- 实车安全、长时间稳定性或现场演示能力。
