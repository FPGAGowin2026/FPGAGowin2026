# 项目完成度报告

更新日期：2026-08-23

## 1. 结论

按“最终能够稳定完成现场演示”计算：

- 总体完成度：约 **21%**。
- 剩余工作量：约 **79%**。
- 合理估算区间：19%～23%。
- 当前阶段：方案、主机通信和高级功能仿真底座已建立，FPGA 官方以太网 RTL 已进入功能仿真，但坏 FCS 拒绝和实板工程尚未闭环。

该比例不是按代码量或工期计算，而是按最终演示所需的 FPGA、底盘、传感器、导航、AI 和稳定性门槛加权。当前前期软件基础完成较多，但尚未形成完整实板运动闭环。

本报告对应当前分仓发布基线：`fpga_rtl` 为 `9107a6b`，`fpga_gateway` 为 `88f760c`，`robot_bringup` 为 `c188c99`；三个高级功能包、依赖脚本和本文档由父仓库直接发布。

| ROS 主机通信底座 | 10% | 约 80% | 网关、模拟器、bringup、4 项协议 GTest 和 1 项 launch 回归已完成 |

| FPGA 以太网与协议 RTL | 12% | 约 10% | 已导入官方第 58 章 RGMII/UDP 回环 RTL；有效帧仿真有通过记录，坏 FCS 拒绝失败，尚无本项目协议 RTL、综合或实板证据 |
| 电机闭环与物理安全 | 15% | 0% | 编码器、PWM、PID、限幅、急停、堵转和看门狗均未实装 |
| 摄像头、IMU、测距与显示 | 12% | 0% | 尚无传感器 RTL、DDR3/HDMI 顶层或实板验证 |
| FPGA 绕障与独立路径 | 12% | 0% | 测距减速、停车、绕障和运动段队列尚未实现 |

## 3. 已完成工作

### 3.1 架构与协议

- 已确定 ACG720 与 Jetson Orin Nano 的职责边界。
- 已冻结 FPGA 独立模式与 Jetson 协同模式的安全优先级。
- 已定义固定二进制 UDP 报文、黄金向量、端口和频率目标。
- 父仓库、`fpga_rtl`、`fpga_gateway` 和 `robot_bringup` 的仓库边界及同步方式已建立。

### 3.2 ROS 主机侧

- `fpga_gateway_node`、`fake_fpga_node` 和 `robot_bringup` 已实现。
- 4/4 协议 GTest 已通过。
- 主机仿真闭环已验证约 100 Hz 遥测、速度命令、200 ms 命令超时归零、软件急停和断链诊断。
- `robot_navigation` 已用 `robot_localization`、`slam_toolbox` 和 Nav2 完成合成传感器点到点导航。
- `vision_bridge` 与 `mission_control` 已完成合成红色目标的搜索、对准、接近和停车闭环。
- 上述三个高级功能包的运行时节点已迁移为 C++17/`rclcpp`，对应纯算法回归已改为 GTest；Python 只保留给 ROS 2 launch。
- 当前五包已在独立 `/tmp` 构建目录复验成功；4 项协议、1 项 UDP launch 和 3 项算法共 8 个直接用例通过。`colcon test-result` 显示的 13 条记录包含 CTest 包装层重复汇总，不能当作 13 个独立用例。
- 同轮运行复现 `120×80 @ 0.05 m/pix` 地图、Nav2 从 `(0, 0)` 到 `(1, 0)` 成功和任务状态到达 `COMPLETE`；网关与 bringup 发布版本还增加了待实车标定的里程计/IMU 协方差初值。

### 3.3 FPGA RTL

- 模式仲裁器已实现独占选源、安全强制置零和停车后切换。
- Verilog-2001 编译和 15 项自检已通过。
- 已从官方第 58 章工程导入 RGMII/GMII、IPv4/UDP 收发和回环模块，并新增自检 testbench。
- 已有记录表明 72 字节有效帧回环通过；坏 FCS 帧虽然被标记为错误，仍会进入发送路径，因此负向用例尚未通过。
- 以上只证明独立模块和通用 UDP 回环的 RTL 仿真状态，不证明本项目应用层协议、Gowin 综合、时序、顶层集成或实板安全。

## 4. 剩余工作

### 4.1 FPGA 网络与协议

- 补齐 Icarus Verilog 环境，重复有效帧和坏 FCS 测试，并修复坏 FCS 帧仍进入数据/发送路径的问题。
- 完成官方 RGMII/GMII、ARP、Ping 和 UDP 回环的 Gowin 综合与实板验证。
- 固化实际时钟、复位和板卡约束。
- 实现 FPGA 端报文解析、CRC、序号检查和遥测发送。
- 在电机禁用状态下完成 FPGA—ROS 黄金报文实板联调。

### 4.2 FPGA 安全与运动

- 将模式仲裁器接入真实顶层并完成 Gowin 综合。
- 实现物理急停接口、看门狗、速度与加速度限幅。
- 实现编码器、PWM、方向控制、速度 PID 和堵转检测。

### 4.3 感知、避障与独立演示

- 完成 OV5640、IMU、三路测距和 HDMI 状态显示。
- 完成测距减速、停车、绕障和运动段队列。
- 完成 FPGA 独立路线连续演示和实车参数标定。

### 4.4 Jetson 高级功能

- 在 Jetson 上运行依赖安装脚本重建本地 `ros_ws/src/external` 覆盖层，或经确认后改用系统级 Humble 依赖；该本地目录不上传。
- 接入真实 IMU、2D 激光雷达和相机，测量 TF 外参并标定融合协方差。
- 用真实数据替换合成激光与相机，保存 rosbag、地图和导航成功率证据。
- 选择单个 TensorRT 目标模型并把输出适配到 `/vision/target_observation`；当前红色阈值算法只作为接口基线。

### 4.5 系统收口

- 验证断网后 200～300 ms 内关闭 PWM。
- 验证图像满负载不阻断控制通道。
- 完成故障注入、1～2 小时连续运行和现场演示材料。

## 5. 当前关键路径

后续按以下顺序推进：

1. 修复官方 UDP 回环的坏 FCS 拒绝路径并恢复可重复仿真。
2. 完成 Gowin 综合、RGMII、ARP、Ping 和 UDP 实板回环。
3. 电机禁用状态下完成 FPGA—ROS 黄金报文实板联调。
4. 仲裁器接入顶层并完成 Gowin 综合。
5. 急停、看门狗、限幅和架空车轮电机闭环。
6. 摄像头、IMU、测距、绕障和独立路径。
7. ROS 融合、SLAM、Nav2。
8. AI、网络传图和稳定性收口。

当前唯一下一最小闭环仍是 **FPGA 网络基线**。主机高级功能已有可运行仿真基线，在硬件链路完成前不继续扩展算法、模型或网络传图。

## 6. 风险与证据边界

最大风险来自尚未开始的实板链路、电机和传感器集成。实际引脚、电平、电机驱动、编码器分辨率和传感器型号仍未固化，可能显著改变实施工作量。当前 UDP 回环 testbench 的有效帧通过与坏 FCS 失败来自已有运行记录；本轮环境缺少 `iverilog`/`vvp`，尚未现场复验。ROS 构建、测试与完整主机仿真已在本轮复验，但仍不能替代实物证据。

当前结果不能证明：

- Gowin 综合、布局布线或 RGMII 时序正确。
- 本项目 FPGA 端 CRC16、序号、心跳、PHY 断链和 PWM 看门狗有效；官方通用 UDP/FCS 逻辑不能替代这些协议证据。
- 电机、传感器、SLAM、Nav2 或 AI 可以在实物系统运行。
- 实车安全、长时间稳定性或现场演示能力。
