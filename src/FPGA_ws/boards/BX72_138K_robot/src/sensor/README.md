# FPGA 传感器及四轮 I/O

`n10_packet_parser.sv` 和 `imu660rc_spi_reader.sv` 从旧项目固定版本中单独选取，没有引入旧导航固件。N10 的帧头、58 字节长度、16 个距离点和累加校验与工作区的雷达资料相符。`n10_receiver.sv` 是可单独测试的串口接收封装；当前整机顶层使用 `robot_control_core.sv` 中的串口接收与包解析器。原始雷达角度仍需经过安装外参和方向转换。

N10 的 `packet_received_us_o` 是完整数据包的 FPGA 接收时间，16 个点共享这一时间；它不是逐点真实采样时刻。使用该时间进行去畸变或融合时，必须把串口传输和雷达扫描造成的不确定性计入处理。

IMU 采集器使用 LSM6DSV16X 的 SPI，旧配置为陀螺仪 ±500 dps、加速度计 ±4 g、输出数据率 120 Hz，原始值尚未转换到车体坐标。传感器安装方向、零偏和实际通道还需要确认。

`robot_io.sv` 是可单独测试的传感器及四轮 I/O 封装，未直接用于当前整机顶层；实际接线和跨时钟域处理位于 `robot_control_core.sv`。默认电机通道、编码器通道及反向设置取自旧项目，已进行离地空转测试，地面方向仍需确认；输入命令需要经过实时近障保护、运动许可和必要的通信超时处理。
