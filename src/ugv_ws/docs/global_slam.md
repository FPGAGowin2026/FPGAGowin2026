# 全局建图与航点调度

Jetson 使用 ROS 2 Humble 的 slam_toolbox，接收 FPGA 融合位姿和前向雷达扫描，发布全局占据地图与 `map → odom` 变换。启用回环检测不代表现场回环效果已经验收。扫描没有逐束硬件时间，运动畸变及侧后未观测区域仍是限制。

网页提交 `map` 或 `odom` 航点。Jetson 的全局规划节点在全局地图上规划路线、融合新鲜局部占据并分段调度；FPGA 使用局部栅格复核和执行。地图坐标目标在派发短段时转换为 odom；变换变化需要重规划时，先取消旧段并等待执行器终态。接收目标、设备到达和真实停车是不同状态。

标准 `car_bringup` 默认启动全局地图与导航节点。`config/global_slam.yaml` 控制地图参数；配置和外参需按设备调整。若 FPGA 重载、会话变化或里程域变化使 `boot_id` / `odom_domain` 改变，适配器暂停旧全局图；重新启动 bringup 会开始新地图，不自动恢复旧位姿图。

保存可继续建图的位姿图或导出栅格时，请使用 slam_toolbox 的 `/slam_toolbox/serialize_map` 服务和 `nav2_map_server`；网页下载的 JSON 是显示用地图，不是可直接恢复的位姿图。测试范围见[验证记录](../../../docs/验证与部署.md)。
